# Интерфейсті бағалау (14 апта)

* **Бағалаушы курстас:** Әлихан Серіков (топ курстасы)
* **Енгізілген өзгеріс:** Болжау формасы (`03-predict-form`) мен болжамдар тізімі (`04-predictions-list`) экрандарында «Басты бетке қайту» батырмасы жоғарғы панельде айқын етіп бекітілді және күн/уақыт өрісіне нақты формат үлгісі (`ЖЖЖЖ-АА-КК СС:ММ`) қосылды.

| № | Тапсырма | Орындалды ма? | Қай жерде қиналды? | Не түзетілді? |
| :--- | :--- | :--- | :--- | :--- |
| 1 | Қауіп деңгейін болжау формасын толтырып, сақтау | Иә | Уақыт өрісінің нақты форматын енгізуде сәл кідірді | Күн/уақыт өрісіне `ЖЖЖЖ-АА-КК СС:ММ` үлгісі және түсіндірме қосылды |
