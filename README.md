# Almaty Road Risk Prediction

Жоба Алматы қаласындағы жол апаттарының қаупін жасанды интеллект арқылы болжайтын веб-жүйені әзірлейді. Жүйе жүргізушілерге, қала қызметкерлеріне және жол қауіпсіздігі мамандарына қауіпті аудандар мен уақытты алдын ала көруге көмектеседі.

## Мақсаты

Тарихи апат деректері мен ауа райы негізінде Алматыдағы жол апаты қаупін болжайтын веб-жүйе жасау.

## Пайдаланушылар

* Жүргізуші
* Жол қауіпсіздігі маманы
* Қала әкімшілігінің қызметкері
* Әкімші

## Талаптар

1. Жүргізуші аудан, күн және уақытты таңдап, қауіп деңгейін алады.
2. Жүйе қауіп деңгейін картада түспен (төмен / орташа / жоғары) көрсетеді.
3. Қауіп жоғары болса, жүйе ескерту хабарламасын көрсетеді.
4. Маман тарихи апаттар статистикасын аудан бойынша қарайды.
5. Әкімші апат деректерін CSV файлмен жүктейді.
6. Әкімші болжау моделін қайта оқытып, нәтижесін тексереді.
7. Жүйе енгізілген деректерді тексеріп, қате болса түсінікті хабарлама береді.
8. Жүйе әр болжау сұрауын деректер қорына сақтайды.
